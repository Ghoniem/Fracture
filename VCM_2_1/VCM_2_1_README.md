# Crack Network Evolution

The objective of this version is to develop methods for generating and evolving crack networks in uniform and non-uniform externally applied stress fields.

## Features

- **Validation of Known Solutions**: Continue validation of known solutions for kinked, branched and curved cracks. Determne optimal simualtion parameters.
- **Polyline Crack in Uniform External Field**: Simulate the growth of a polyline crack in an externally applied uniformstress field.
- **Optimization Studies**: Find the best parameters that control the angle and length of added segments as the crack propagates.
- **Polyline Crack in a Compressed Disk**: One way coupling of the BEM solver to the growth of a polyline crack.
- **Visualization**: Multiple visualization modes for different analysis needs
